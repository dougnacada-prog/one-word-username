A program that writes exactly our own make.fun username — dougnacada-prog — to /output/entry.txt, the whole entry for make.fun's One Word, One Username, One Reward bounty. One word, no explanation, no pitch: the entrant's own handle, and a judge model picks the funnier or more interesting of two at a time.

## Run it

```sh
node main.ts
```
